# Travel Blog

A responsive travel blog created as a group project during our Full-Stack Developer training.

The project focuses on a modern and responsive frontend experience for discovering travel destinations, reading articles, and exploring travel-related content.

## Features

* Responsive design for desktop and mobile devices
* Travel destination highlights
* Interactive article slider
* Multiple travel article pages
* Video integration
* Article information and author sections
* FAQ section
* Contact form
* Social media and article sharing elements
* Responsive desktop and mobile navigation
* Imprint and privacy pages

## Tech Stack

* HTML5
* CSS3
* Git
* GitHub

## Team Project

This project was developed collaboratively as a group project during our Full-Stack Developer training.

The project gave us practical experience working together on a shared codebase, coordinating different parts of a website, and using Git and GitHub for collaborative development.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/TobiasIllnerDev/Blog-Projekt.git
```

Open the project folder and launch `index.html` in your browser or use a local development server such as Live Server.
